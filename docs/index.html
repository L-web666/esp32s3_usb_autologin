开始烧录

当前浏览器不支持 Web Serial
请使用桌面版 Chrome / Edge / Firefox （不要用手机或 Safari） 需要通过 HTTPS 访问
当前页面不是安全上下文，无法调用 Web Serial。
安装过程会清空整个 Flash，包括已保存的密码和文件系统。 这是有意为之：确保分区表和文件系统回到干净状态。

操作步骤

  1. 用 USB 数据线把板子接到电脑。 建议插板子上标 USB / UART 的 CH340 那个 Type-C 口， 兼容性最好。
  2. 点上面的蓝色按钮，在弹出的串口列表里选择板子对应的端口 （通常显示为 USB-SERIAL CH340 或 USB JTAG/serial debug unit）。
  3. 选 Install，等待进度条走完（约 1~2 分钟）。
  4. 出现 Installation complete 后，拔插一次 USB。
  5. 按下面的「烧录后配置」设置密码。
连不上 / 找不到串口怎么办？
  • 换一根支持数据的线（很多线只能充电）。
  • 手动进入下载模式：按住 BOOT 键 → 点一下 RST → 松开 RST → 松开 BOOT。
  • Windows 上如果没识别到 CH340，需装 CH340 驱动。
  • 关掉占用串口的程序（串口监视器、Arduino IDE、其他烧录工具）。
  • 换个 USB 口，不要用 USB Hub。

烧录后配置（设置密码）

固件默认 autoLogin: true，但密码为空。有两种方式设置：

方式 A — 串口命令（推荐，不用再烧录）

把板子的 CH340 口接到电脑，用任意串口工具（波特率任意） 连接后发送： 

setpwd 你的Windows密码

板子会回复 OK 已保存密码，并立即用它登录一次。密码保存在 NVS，掉电不丢。

命令作用
setpwd <密码>保存密码并立即登录
getpwd查看是否已设置（只显示长度）
clepwd清除已保存的密码
autologin立即执行一次自动登录
status查看当前状态
help列出所有命令

方式 B — 改配置文件

从源码仓库下载 data/data/settings.json，修改 loginPassword 字段，然后用 PlatformIO 执行 pio run -t uploadfs 烧录文件系统。

使用提示：把板子插到目标电脑后等约 4 秒，密码会被自动输入。 如果电脑已在桌面（未锁屏），密码会被打进当前焦点窗口—— 建议先按 Win + L 锁屏再插板子。
